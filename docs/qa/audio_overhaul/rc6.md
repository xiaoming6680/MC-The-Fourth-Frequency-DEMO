# RC.6 老式开屏、镜头入屏、血字墙与混音

## 当前实现

- 游戏开屏用老式 CRT 测试卡；终端首次自检用内存灯与示波曲线；音量页到告知页用 20 Tick 扫描恢复。日常终端短自检删除。
- 确认后用 64 Tick 镜头推进，MC 菜单先出现于玻璃内，随镜头放大；实体边框离开视野，反光／扫描线和五阶轻失焦后处理消退。帧请求不残留。
- 首次世界崩坏保留原结构，取消尝试过的空间线框加载。血字墙只密铺「败」，删除夹杂文字和左下角计时。铺屏前加入两句冷淡警告；初版卡机起音加强，74 ms 重复和黑屏截止节拍保留。
- 200 份常规前景文件实测 RMS 增加 1.78–4.38 dB，输出倍率提高至 2.6；终端提示仍为 1.25。背景床乘 0.85，未渲染层环境床独立乘 0.80。
- 三份崩坏声峰值约 -4.44 dBFS，RMS 增加 4.24–4.72 dB。仍使用初版来源，未添加噪声。31 份终端／警告文件、九份初版底噪和初版震动提示保持原始文件身份。

逐文件数据见 [电平报告](rc6-levels.json)。母带保持时长、Vorbis/44.1 kHz，验证解码真峰、循环接缝与原始素材哈希。空间半径、服务端包和各玩家配置不变。

## 验证结果

- 独立副本：`3c77e8e` + 本次开屏／音效改动。排除其他任务的未完成代码和模型；共享工作区的其他改动保留。
- 最终 `build`：成功，861 单元测试、99 服务端 GameTest 全部通过；60 个 mixin 类和 22 个 Minecraft 注入目标的 remap JAR 校验通过。
- 完整 `all` 客户端：成功，10 分 37 秒，覆盖主线、工具、终局、实体、终端、屏幕滤镜和音频生命周期。
- `notice-entry`：成功，9 张真实截图；断言页间控件门控、GPU 镜头滤镜应用以及返回菜单后的清理。
- 音频：242 份非音乐文件解码、电平与循环验证通过；原始底噪、震动提示及未重做终端提示的哈希保持一致。真实音频通道覆盖初次／持续／刷新／静音和两类环境床。

客户端导航夹具原先只等待 5 Tick 就读异步状态，满套运行时会早于服务端响应。现按传送门开始／停止和要塞开始各自的真实工具与活跃状态等待，最多 40 Tick；保留原有断言，生产导航逻辑未修改。修订后完整客户端套件通过。
