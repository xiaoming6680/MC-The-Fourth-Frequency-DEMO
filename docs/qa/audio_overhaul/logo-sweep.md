# 扁平 Logo 与恢复扫频

按玩家最新要求，开幕使用简洁扁平的六边形 CRT 绿色 Logo，内部是断开的信号线与终端光标；取消旧测试卡。Logo以30 Tick（约1.5秒）点亮、短暂停留、淡出，之后进入音量页。音量页到告知页恢复20 Tick（约1秒）的扫频，终端自检和进入MC的镜头不变。

内置ImageGen的最终素材原样保存为1254×1254 RGBA；四角实际透明，未采用带棋盘格背景的候选图。`fabric.mod.json`的icon与开幕引用同一PNG。最终提示词及资源路径见[素材记录](../../art/mod-logo.md)。
