# RC.5：音效放大、滑块反馈与初版底噪

游戏总音量调高会同时增大原版声音。本次直接提高 MOD 音效相对于原版的输出增益，不改写玩家的原版音量设置。

| 类别 | 相对 RC.4 的输出增益 |
| --- | --- |
| BOSS 攻击、实体动作、异常事件、开屏卡音等主体音效 | 1.8 倍，未达到通道上限时约 +5.1 dB |
| 终端主动操作与重要结果的轻提示 | 1.25 倍，约 +1.9 dB |
| BGM、常驻信号底噪与 BOSS 环境底声 | 不变 |
| 原版与其他 MOD 的声音 | 不变 |

滑块移除循环扫频，只保留限频轻刻度；成功锁定替代当次刻度声，松开不追加声音。

“终端传来剧烈震动”的提示恢复 `2913817` 初版 `device/terminal/anomaly/01.ogg`，素材逐字节一致，沿用原有预警音高与个人通知链路；来源见 `docs/art/audio/original_cues.json`。重建脚本会保护它，普通引导文字仍不发声。

引导弹字仍无声，终端和环境底噪恢复初版，包含终端载波、四种信号床、三个 BOSS 阶段环境声和未渲染层环境声。9 份文件与 Git 中首次加入的版本逐字节一致，来源提交与 SHA-256 记录在 `docs/art/audio/original_beds.json`。终端底噪随界面启停，不与滑块联动，也不参与音效放大。零音量仍保持静音，单通道增益限制在 0–1；不同响度的音效在达到上限时实际提升幅度会不同。

增益仅应用在客户端 SoundEngine 最终输出：覆盖初次播放、Tick 持续更新和分类音量刷新。原始 SoundInstance 音量与服务端声音包不变，因此不会扩大衰减半径，也不需要服务器扩大声音发送范围。多人客户端分别处理自己的输出，不修改其他玩家设置。

其余新制作音效去掉持续白噪底层，颗粒接触改用有间隙的共振短声，激光持续声和起射声去掉宽频嘶声，保留动作与冲击时点。原版声音、BGM 和基于初版素材的开屏卡机段未改写；录音素材激光/触手样板仍待试听，未替换进游戏。

客户端验证除现有开屏、终端静音引导、BOSS 声音生命周期外，还读取实际 OpenAL `AL_GAIN`，比较 MOD 瞬态声、持续声和原版声音。检查连续分类刷新不重复乘增益、持续声音量变化正确、分类静音仍有效，以及原始音量未被改写。
