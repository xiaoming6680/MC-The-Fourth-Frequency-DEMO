# 人工验收清单

面向 `1.0.0-rc.6` 候选包，**只列自动化覆盖不到的项目**。每条写成「做什么 → 通过标准」，理由不在这里：规则见对应专题文档，取舍见[设计札记](design-notes.md)。

自动化结果与命令见[测试与验收](testing.md)。

## 验收前准备

- Minecraft 1.21.11 / Fabric Loader 0.19.3 / Fabric API 0.141.4+1.21.11 / Java 21。
- 安装 `thefourthfrequency-1.0.0-rc.6.jar`，首次验收优先使用新存档。
- **先备份存档**：末地结局会给当前存档建立本地隔离标记。
- 默认关闭开发加速：`pacing.developerAcceleration=false`。
- 需要从中断的结局事务恢复时，以 `-Dthefourthfrequency.safeMode=true` 启动一次。

## 首次开屏（两页：音量校准 → 安全告知）

告知版本已升到 v4，确认过 v3 的老玩家也会再看到这两页各一次。

| # | 做什么 | 通过标准 |
|---:|---|---|
| 1 | 清除本地安全告知版本文件后进标题页 | 开机扫描点亮的是**音量校准页**：「总音量」小节标题、滑条、右侧「试听」、滑条下一行说明、页脚一行、底部「下一步」。**页面上没有成段解释文字**；三个控件要等开机动画跑完才可点 |

## 首次崩坏加载屏

保留首次崩坏结构，不插入新的加载动画。演出最短 250 Tick，资源重载额外等待有上限。

1. 普通加载文字开始出错，随后出现「请勿回应。」和「它看见你了。」；提示固定位置，屏幕媒介失真。
2. 第 132 Tick 血字墙一帧铺满，所有文字均为「败」，包括四边；不得夹杂其他词句或左下角计时。
3. 铺屏瞬间有短促冲击声，继续初版 74 ms 卡机片段重复；第 160 Tick 画面冻结，第 172 Tick 黑场停声。降低 MOD 音量能减弱刺激，静音必须完全无声。
4. 恢复旧版加载画面；资源重载不露出现代加载界面。断线或被踢出时声音停止，后续加载不重播首次崩坏。

### 碎片信号与线索（19a / 19b）

**在标记地点走进那类结构就该有信号。** 挑一条**废弃矿井**候选（沙漠神殿之类一进门就到的结构复现不出这一项）：按记录坐标过去、挖下去、进到任意一条矿井走廊——接收器就应可用。判定只有两条：**站在该类结构的某个部件内**，且**结构离标记坐标不超过 320 格**。

**线索是探索途中收到的（需要新世界）。** 老存档开局就分配好了四条候选，复现不出来。开新世界，波段推进到 1 以上后正常出门探索：

- 走一段路后 `RECORDS` 里应**陆续**冒出候选行，而不是开局就有四条（无线索时每 20–45 秒一次随机扫描，出了线索后放缓到 1–3 分钟）。
- 报出来的地点必须是**你附近的**（两百格量级，不是几千格外）。可以是你还没看见的东西。
- **记录里能看到的线索，导航里就必须能选。** 候选行一出现（不需要先进下界、不需要卡关五分钟），行尾的 `[打开导航]` 按下去就应当直接把导航目标切到**这一行**的地点，导航页同时出现 `[可选文件调查]`，且目标选中后**「启动导航」按钮必须在**——不是只有读数没有按钮。反过来：记录里没有可跟的线索时，那一行也不应留着按不动的 `[打开导航]`。
- 打开导航跟过去，**坐标应当直接落在结构上**，而不是它起始区块的角；HUD 上的高低差应当是真实的（地下矿井给负值）。
- **不得卡住**：所在区域根本没有对应结构时（整片海、超平坦），继续探索若干次扫描后该碎片应退而接受附近**任意**一处结构。四份隐藏文件必须始终拿得到。
- 服务端不得掉帧：扫描每 10 Tick 最多给一名玩家做一次，只读已加载区块，**绝不能**因此生成新区块。

### 导航读数常驻 HUD（20）

选中矿物工具并锁定一处铁矿，关掉终端，确认物品栏上方常驻一行与终端首页**逐字相同**的读数。然后：

- **走动时距离实时变化**，不需重开终端；上下爬一格，高低差立刻跟着变（客户端算的，最容易出错）。
- **把终端收进背包（不拿在手上）读数仍在**。
- **它只有一行，不刷屏**：走一段路后通知栈没有被导航信息填满；期间触发一次任务完成，那条通知正常浮出、显示在读数**上方**，读数没被顶掉。
- **清除目标后约 1 秒内自行消失**，不需要任何提示音或额外消息。终端给别人 / 死亡掉落后同样消失。
- **追逐期间读数不显示。**
- 六种导航类工具都试一遍。要塞只给方向不给距离，与终端内一致。

**局部规则坍缩（`local_rule_collapse`）**——从调试面板触发：

- 玩家周围 7×3×7 区段立即全黑，同一区域出现少量分散的材质丢失碎片，**这些碎片在光照恢复后仍然留着**。
- **触发时没有任何音效。**
- 挖掉或放置一个方块，该方块所在区段单独恢复光照，相邻区段仍黑——**逐区段恢复，不是一次全亮**。
- 全程用 F3 检查真实亮度值不变；服务端刷怪、光源方块状态和其他玩家画面都不受影响（多人需另一名玩家在场确认）。
- 什么都不做时 30–40 秒后自行全部恢复。
- 触发后立刻切维度、死亡或断线重连，回来不得残留黑区。

### 天气工具的天空监测

1. **无异象时**：四个通道（天顶、地平线、星等、天体相位）给出稳定读数，地平线走势线平直，页面**完全干净**。昼夜倒计时全程不塌成 `——`。
2. **`red_horizon`**：地平线通道在天色明显变红**之前**就开始爬升，可见为爬坡而非跳变。随强度依次出现扫描线 → 滚动带与撕裂行 → 故障行从卡片底部涌入 → 峰值期每约两秒一次的短爆发。
3. **爆发最猛时**四个顶部标签、工具返回按钮与右下角关闭提示**始终可读可点**，撕裂行和花屏不得溢出卡片。窗口拉到最小和最大各验一次。
4. **`metric_drift`**：昼夜倒计时**必须始终正确**，只有天体相位通道报出偏差；终端报出的距离与坐标出现偏差而导航与到达判定仍准确。演出不得超过最低一级（只有扫描线与偶发整行 `——`），全程不得出现撕裂行。
5. **PIN 到 `HOME`**：首页卡片说同样的话（同样会塌成 `——`），但不得出现扫描线、刷屏或花屏。
6. 其余五个工具与 `HOME`/`RECORDS`/`FILES` 三页在异象期间**完全无演出**。
7. 故障行必须是仪器语言（无载波、采样被拒、相位基准丢失等），**不得出现伪造的异常名或堆栈**。

## 未渲染层与细菌

用调试面板触发（异象列表最后一行）。被拒绝时面板会直接说出是哪一条拒绝的。

| 检查 | 通过标准 |
|---|---|
| 进入 | 顺序是**先看着自己往下沉约半秒**（视角穿过地板，人物不动、不掉血、不卡方块），**然后**才黑屏约 1 秒。**不能看到区块在眼前拼出来。** 黑屏散开那一帧视角还卡在天花板里 |
| 环境音 | 进层后 2 秒内淡入 20 秒循环底噪，细菌出现前无配乐，出现后 `music_unrendered` 在底噪与心跳下方播放；出层后 2 秒内淡出。反复进出不叠加成两层。判据是**它不盖住脚步声和心跳** |
| 视距 | 锁到 6 区块，视频设置滑块不可调。主干长廊尽头应消失在雾里而不是一眼望穿 |
| 挖不动 | 钻石镐挖墙/地板/天花板**一格都不掉**；放方块、倒水、打火石全部无效 |
| 找出口 | 出口是一片 15×15 的**假墙包着假地板**，只有约 20% 色差。**这个色差是唯一需要用眼睛定的参数**（`tools/generate_unrendered_textures.py` 的 `LIGHTNESS_SHIFT`）：远看能骗过去、正面对着看能认出来。走进假墙**直接穿过**，没有碰撞没有提示；再走一步地板放手。假墙必须**挡光、挡视线** |
| 终端提示 | 细菌落地那一刻弹一次「检测到异常信号」，**只有这一句**；约 3 秒后同一行变成常驻「探测到主世界信号：【方位】」，八方位、**不闪**。**按它走应当真的能走到出口。** 站到出口 20 格内时停止刷新并自然淡掉 |
| 从天上回来 | 穿墙后黑屏 → 散开时人已在进入点正上方约 200 格下落。**黑屏散开那一刻不能看见区块在往里加载**；下落全程视距 16 区块，落地那一刻收回；**落地不能掉血**。超时（走满六分钟）应是**地面返回** |
| 中断路径 | 在层里分别执行：退出游戏再进、`/kill`、管理员 `/tp` 传走、关服再开。四种都不能把人留在层里，也不能回来后重复传送 |

**细菌（需要掐表）**：进层满 1 分钟后放下，出现在 100 格以外、**你看不见它生成**。

- **手感**（数字已由 `runGameTest` 每轮验证，这里验的是手感）：主干长廊上一直疾跑，它应**缓慢**拉近；改成疾跑跳才拉得开。
- **心跳**：它落地时在 100 格外、超出 64 格听程，所以「检测到异常信号」之后是一段安静；等它走近，心跳从远处淡进来并越来越响，**用耳朵应当能判断它在哪个方向**。绕柱子走一圈确认左右声像。
- 打它、推它、用盾撞它，都应当**没有任何反应**。
- 被碰到：屏幕黑 → 尖叫 → 在自己重生点醒来，血量饱食度满。**不得出现死亡界面、聊天死亡播报或掉落物。**
- **环境音音量**：这条现在只有一个旋钮——`UnrenderedLayerClient.AMBIENCE_VOLUME`（当前 0.11，文件固定在 −20 LUFS 参考电平）。**不要同时改文件和常量**，那正是上一轮把它压没的原因。
- **入场黑屏必须盖住加载屏**：踩空下坠约半秒后拉黑，然后传送。**全程不能看见「地形加载中」的进度画面或区块拼装**。黑屏计时在加载屏期间是暂停的，所以无论加载多久，落地后都还有约一秒实打实的黑。
- **被抓住时黑屏要等尖叫放完**：细菌够到你 → 黑屏 → 尖叫（约 3.8 秒）**完整播完**之后画面才回来。中途黑屏散开、尖叫被切断，是回归。普通追逐被抓也是同一条要求。
- **两条尖叫都在崩坏音之上**：未渲染层 −5.0 LUFS（全模组最响），追逐 −7.8 LUFS，都高于 `alpha_corruption_collapse` 的 −9.2 LUFS。应当明显比它盖着的崩坏音突出；如果盖过了别的东西太多，改的是素材电平而不是播放音量。
- **细菌的形体**：现在是一个核心加十二个不同尺度、各自错开旋转的叶片，每片按自己的相位起伏。验收看两点——**远处轮廓不能读成一堆方块**，以及**站着不动看十秒，轮廓应当一直在变且看不出规律**。
- **终端提示的面板**：层内的方位提示现在走 MOD 的通知面板（不是原版 actionbar），有自己的冷灰色背景。在满屏黄墙前应当一眼可读。

## 末地天气

- **必须在下雨**：从主世界过传送门进末地，雨应在约 3 秒内**渐入**而不是一进去就满强度；抬头有可见雨柱，地面有溅射粒子，能听到原版雨声。
- **不能有云**：任何位置抬头都不得出现云层。把游戏设置里的云开到「华丽」再看一次——仍然不得出现。
- **时不时打雷**：静待 3–5 分钟应听到若干次雷声，平均约每 40 秒一次，**带方位**（左右耳有差异）；不得出现两声挨在一起（间隔小于 4 秒），也不得整段完全没有。
- **雨不能变成一堵墙**：打一场完整战斗，雨的强度始终在「能看清场地」的范围内，尤其在激光扫射和天矛落地这些同时叠着色散滤镜的瞬间。
- **什么规则都不改**：在末地点一堆火或放营火，**不会被雨浇灭**；作物、铜氧化、生物生成等一切与天气相关的行为都与之前完全一致。
- **主世界必须没被牵连**：进末地待几分钟再回主世界，天气与进去之前一致；退出重进存档再确认一次。**这是这个特性最重要的一条边界。**
- **离开末地要立刻停**：传送回主世界或下界的那一帧起，不得再有任何雨、雨声或雷声。
- **打赢之后要停雨**：本体死亡演出结束后，雨应在**约 10 秒内渐弱到完全没有**，期间不得再响新的雷；之后站在出口传送门旁抬头，天是干净的。**渐弱不能是一帧切断。**
- **赢完离开再回来仍然是晴的**：打赢后回主世界再进末地，**不得重新下一遍雨再淡出**，应该一进去就是没有雨的。
- **打输不停雨**：失败结算路径上雨照常，这条是刻意的。

## 世界接口战斗

### 数值与结构

- 最大生命 `600 × (1 + 0.5 × (人数 − 1))`：1 人 600，8 人 2700。
- 形态按生命单向推进：`>70%` / `>35%` / `≤35%`。
- 崩塌计时 12000 Tick（10 分钟）；任一冻结成员在线就继续，全员离线时暂停。
- 存活锚每座每秒回复 0.02% 最大生命（10 座合计 0.20%），投射可见的半径 8 格稳定区；区内玩家受到的伤害 −20%，区内地形不出现战斗擦伤或缺失材质。
- 战斗只显示一套自定义 HUD；永久伤痕总预算 8192 格、每 Tick ≤32 格，并保护返回传送门、黑曜石柱、方块实体、关键 MOD 方块和免疫标签。

### 稳定锚（需要客户端人工验收）

- 柱顶站的是**四向夹具**而不是末影水晶：正、侧、后视一致，俯视清楚读成四爪夹紧，四足向内扣住柱顶那一格基岩帽。
- **牵引束端点**从中继核（锚上方 2 格）出发，实时连到移动中的 BOSS 核心；不是从锚体内部出发，也不是固定竖直光柱。BOSS 上升、下降、绕场时束线角度应跟着变。
- **破坏演出**：先向外炸开（中继核引爆、三圈爆轰波、垂直光柱、26 格冲击环），之后才接回向内内爆与紫色余烬；相机在**自己拆的那座锚**旁边震得最厉害。
- **旧存档迁移**：用 Beta 0.4.0 及更早版本准备过场地的存档进入末地，10 个锚全部呈现为新实体；已持久化为已拆的锚不得复活，柱顶不残留末影水晶。**竞技场之外的普通末影水晶行为必须完全同原版。**
- 分别以 0、1–9、10 枚已拆锚完成成功结局，终末之诗应选用全数保全 / 折中 / 全数拆除三种对应段落。

### 本体几何（需要客户端人工验收）

- 三个形态的本体都明显悬在空中，**任何时刻都不得有一部分没入地面**；召唤下落必须停在空中。站在正下方抬头，本体下缘依次约 8 / 14 / 18 格。
- **头部不得穿模到地下**：打到低血量后（结构下垂最严重）站在中央头颅正侧方，整颗骷髅连同**下颌与牙齿**都必须在地面之上。
- **召唤降临停得更高**：十三秒演出结束时本体停在比战斗站位更高的位置并悬停一会儿，随后在战斗前几秒缓慢下压到站位。
- **高空窗口**：每约 45 秒用约 2.5 秒爬升到站位之上 26 格、停留约 8 秒、再用约 2.5 秒下降。**爬升起始应先听到一声飞行音与低吼。**
- **形态切换是飞离**：蓄势后快速爬升到看不见的高处换形态再落回；**不应在玩家眼前原地变形**。离场与落地各有一次冲击环。
- **三颗头会看向目标玩家**：绕圈跑时三颗头转向你——中央头转得最多、两侧头跟随较少；本体转身很慢，**头应先于身体转过来**。
- **头不得「闪现」**：三颗头应当是**连续转过来**的，不得静止几帧再跳一下。正下方也应该能被看到（俯仰上限 60°）。
- **玩家应该追得上 BOSS**：直线跑过去时它不应以同样速度后退；只在比站位更远时才靠近，进入后水平方向停住。
- **判定框跟着动画走**：在做动作时（凝视锁定、天矛、触手抽击、强制驱逐、形态切换）挥向看得见的骷髅仍应命中；挥向骷髅刚离开的位置应当落空。
- **头部判定框对得上视觉**：开启判定箱显示，头的方框下沿压在**下颌**上而不是悬在下颌上方，顶部仍盖住眉骨；头顶那对角不在框内。
- **三颗头不得互相穿模**：三个形态与每种行动的整段演出里，两颗侧头之间、侧头与中央颈之间都看得见空隙；侧颈向外张开，不越过中线。
- 站在地面用近战攻击**中央头颅与它的脖子**：三个形态都必须能打中，命中反馈落在看得见的骷髅/颈段上。侧头更高更小，可以够不到。
- 触手尖端**不触及地面**（末端停在本体下方 4–7 格），地面近战打不到触手——这是当前设定。用远程或站到高处验证判定只覆盖绘制出的最后一节。

### 音频

- **二、三阶段的技能音效必须与一阶段一样清晰可闻。** 逐一确认激光、龙息弹、天矛、触手、扣押、清栏。
- **长阶段后不得消失**：同一阶段持续输出 **3 分钟以上**，尤其在单人第二阶段反复触发抓取、扣押与清栏。**重点复现路径**：故意在召唤前触发 `silent_world`，确认它被就地中断且战斗全程有声。
- **吼叫应当是两层**：末影龙低吼底下压着一层更低的凋零嗓音，形态越大整体越低；不应听成单纯的末影龙叫。
- **配乐必须一直听得见**：三个阶段各打一段，尤其是齐发龙息弹、天矛落地和激光扫射这些最密集的时刻——BOSS 音效可以盖过配乐一瞬，但不得让整首曲子消失。

### 节奏与行动

- **一阶段出手明显更慢**：两次攻击之间 7.5–10 秒，中间有一段真正安静、够把上一次预警想明白的时间。二、三阶段依次明显加快。
- **高空期间照常出手**：抬升的十几秒里仍应挨打（激光、龙息弹、天矛、触手），只是不会再出现抓取投掷。
- 八类行动都应能在定向验收中出现。
- **凝视清栏必须限量**：单人局连打十分钟，同一个人被清栏不超过三次，两次之间至少隔三分钟。多人局确认冷却是**按人**记的。
- 只有被扣押武器进入恢复账本；清栏的热栏物品是普通世界掉落物，不得被账本复制或返还。
- **锁定时屏幕中央必须干净**：紫/红干扰只出现在画面边缘（径向遮罩 `CenterClear` 起点在半径 0.55 / 0.42），中间那一块必须可读。
- **激光类武器命中要有色散**：**在攻击到达那一帧**（光束触地／光柱落地，与震屏、冻帧同一瞬间）画面边缘出现光学色散——不是撕裂带、不是宏块。不是目标的玩家也应看到更轻的一档。
- **本体在攻击间隙要有东西看**：一阶段两次攻击之间的七到十秒里，核心外应有旋转日冕、轮廓上有场、身下落灰，二形态起三头之间有电弧。
- **三处「开火那一帧」必须存在**：①激光 90 Tick 预警期间**不是目标的玩家**也应看到核心聚能，开火瞬间核心白闪与后坐；②天矛蓄力后半段光柱自上而下填充；③触手落地在击退实际生效的半径上抛一整圈粒子。
- **爆破必须震到相机**，且**抖动与爆炸同一瞬间**、不得提前——激光落点扫过身边、天矛落地、龙息弹起爆、触手落地、稳定锚破坏。
- **战斗期间不得触发任何异象**，也**不得出现无关提示**（让队友发现一份文件或完成一项任务，物品栏上方不得弹出）。

### 三形态的武器差异（需要跑满三个阶段）

- **天锚一阶段比一阶段大**：同一场战斗里记下三次天锚的地面标记圈，二形态应明显比一形态大（约 1.8 倍），三形态再明显更大（约 2.9 倍，直径约 21 格）。**三形态那个圈仍必须跑得出去**——站在圈心开始跑，90 Tick 预告结束前应该能出圈。跑不出去就是不通过。
- **激光二阶段起打得更密**：二、三形态扫射时，地面灼痕和伤害判定明显比一形态密（间隔 5→3 Tick、2→1 Tick）。
- **激光二阶段起甩不掉**：一形态直线跑能把光束甩在身后；二、三形态直线跑**不再够**，必须转向。这条是刻意的削弱。
- **十字线读数每个形态都有**：三形态被天锚或激光锁定时，四角标记、进度条和攻击名**必须照常出现**。（曾经短暂地对三形态隐藏过，已按要求撤销。）
- **光束一形态比一形态粗**：二形态明显比一形态粗（×1.45），三形态更粗（×1.9）。**看得见的边就是烧人的边**——贴着光束可见轮廓的外侧站不应掉血，站进去应该掉。
- **三形态是两条光束**：三形态扫射时应看到**两条**光束从核心呈 V 形张开，中间那道缝能站人（站进去不掉血）。**这仍然只算一次攻击**——两条同时开始、同时结束。
- **画出来的光束就是烧人的光束**：二、三形态跑动时，光束落点应紧跟着你（滞后 6 Tick），不应出现光束画在一处、血掉在另一处。
- **三形态会同时来两种**：三形态应能看到天锚和激光与能量弹/触肢**同时**发生，多个天锚圈可以同时张开。**但任何时刻只能有一次扫射在跑**——注意与上一条区分：三形态一次扫射本来就画两条光束，那是同一次攻击的两半，不是两次攻击。

### 可读性（这一组全是看错了会死的项）

- **地面足迹不是法阵**：本体正下方是**白色六边形**（外六边形 + 内六边形 + 中心十字），天锚落点是**紫色圆形符文法阵**。两者必须一眼分得开；地上出现两个长得像的圆形图案就是不通过。
- **锁定形状每种攻击不同**：激光＝环 + 指回核心的放射线；天锚＝环 + 从上方降下来的环；触肢＝**三角形**；扣押武器＝**方形** + 向内箭头；清空快捷栏＝**九颗珠子** + 方形；抓取＝只有向内急收的箭头。被锁定时低头看脚下，应该不用读文字就知道来的是哪一种。
- **玩家视角高度不能有绑定粒子**：被锁定、被抓住时，**眼睛高度不应有任何绕着自己转的粒子环**。只允许脚下，以及头顶 3 格以上。挡视线就是不通过。
- **触肢有来源**：触肢预告期间应能看到一条从本体核心缠绕下来、连到地面圈的轨迹 + 电弧。不应该是地上冒出一个圈然后被不明物体弹飞。
- **扣押武器留占位**：被扣押时槽位里应出现一个红色名字的屏障，写着「暂扣中 · 战斗结束归还」。它**丢不掉也用不了**（试着丢，应被拒绝并给提示），战斗结束后被换回真武器。

### 粒子演出（需要客户端人工验收）

- **不能是药水粒子**：紫色的部分应该是**符文状的大颗粒**（`WITCH`），不是小圆点；高热部分应该是**带拖尾的火焰**（`SOUL_FIRE_FLAME`），所以环看起来是转过去的、螺旋看起来是在走的。看到一团小圆点雾就是不通过。
- **地面法阵**：本体足迹、天锚落点标记、形态切换起落点，应该是**三层套起来的法阵**（外圈符文 + 内圈光 + 向中心飞的符文 + 放射刻线），不是一个孤零零的圈。
- **大爆炸要有音波环**：天锚落地、形态切换半程、能量弹命中，应出现一个**巨大的白色环形冲击**（`SONIC_BOOM`）+ 闪光 + 多个爆炸发射器 + 烟花拖尾。**同一时刻只应有一个音波环**，两个叠在一起是一团白。
- **本体在不打人的时候也要有东西看**：站在场边看本体空闲 30 秒，应看到**三层互不共面、成对反向自转的环**绕着核心转，核心按固定节拍向外吐一层球壳，**血越少节拍越快**。
- **地上要有它的足迹**：抬头找不到本体时低头看地面——本体正下方应有一圈随它移动的环 + 放射条。走到岛的另一端仍应看得见（走 512 格发送，不是原版 32 格）。
- **打中它要有反应**：近战或射击命中，除了自己的暴击粒子外，**被打中的那一点上应贴着一圈环**，并有一条电弧从伤口打回核心。
- **形态切换是三拍**：起手地面的环**向内收**（不是向外炸）→ 爬升途中有螺旋尾迹一直连回起飞点 → 半程那一帧一次性炸开三层球壳与四道倾斜环 → 落地三圈外扩冲击环 + 放射裂纹。
- **激光有方向**：开火那一帧核心前方有**三道横跨射线的环**；扫射期间光束上有两股螺旋在**往地面方向跑**（不是静止的点线），每几 Tick 甩出侧向电弧；触地处有外扩环和放射条。
- **锁定看得见**：被锁定的人**低头之外也要能看见**——脚下平环之外还有两道穿过身体的竖直环，且随读秒收紧。
- **地面标记说得出「还剩多久」**：外圈不变，**内圈随读秒向中心收拢**。
- **能量球能被追踪**：球飞行时身后有螺旋尾迹、身上套着一道横向环；命中爆炸有球壳 + 三圈冲击环 + 放射裂纹。
- **闪烁安全**：以上所有脉冲、收缩、旋转都**不得达到或接近每秒 3 次**。任何一处看起来像在闪就是不通过。
- **掉落物光柱**：吃一次快捷栏清空，九格物品甩出去后**每一个上面都应立着一根光柱**（末端棒柱身 + 紫色顶帽 + 脚下紫环）。捡起来后光柱**立刻消失**；没捡的那些在 despawn 后也不得留下孤立光柱。

### 多人攻击分配（2 人与 4 人各跑一轮完整战斗）

1. **没有人被连点两次**：只要场上还有别的可选目标，同一名玩家不得连续两次被点名。
2. **份额大致均衡**：一整场下来最多与最少相差不超过三分之一。份额不会精确均分，那是刻意的。
3. **第三阶段不会四条预警压在一个人身上**：排程正在锁定的玩家不应同时被齐发的龙息弹瞄准。
4. **触手三连击打三个人**：三名玩家分散站开（间隔 >10 格），三次落点不全在最靠前的那个人身上。
5. **强制驱逐不重复踢同一个人**：4 人局至少触发两次，第二次选的是第一次没被踢过的人；集成服务器房主始终不被选中。
6. **本体不再长期停在一个人头顶**：四人分散时本体停在队伍之间；单人时站位、悬停高度与转向速率应与此前完全一致。
7. **节奏是否合适（RC 阶段唯一的开放问题）**：记录 2 人与 4 人局的通关时间、每人死亡次数和「是否有空档发呆」。
8. **抓取投掷不发假警告**：出现全屏锁定边框与锁定音的玩家，一定就是随后被抓走的那一个。

### 动画的分量（需要客户端人工验收）

在**第三形态**（本体最宽、颈链最长）逐条确认：

1. **每次攻击进行到约两秒时三个头不应「啪」地弹回**：应看到头在两秒内缓缓前倾、随后用约一秒缓缓收回。
2. **保持姿势结束时头是转回来的，不是切回来的**：强制驱逐（颈部 180°）与凝视清栏（96°）幅度最大、最容易看出来。
3. **抓取抛掷松手之后触手是甩出去再落下的**，不是抛出瞬间整组归位。
4. **收势重音仍然存在**，只是被拉长了。完全感觉不到说明拉过头了。
5. **待机 30 秒以上三个头不应有周期性轻微抽动。**
6. **已知未修复**：阶段/形态切换与重启会在动作播到一半时取消它，那一帧仍是硬切。观察到属于已知项而非回归。

### 失败

1. 让崩塌先达到 100%；同 Tick 同时发生致命伤时**以失败优先**。
2. 单人/远程客户端完成失败演出后**游戏不应关闭**：回到主世界、整个世界呈现缺失材质，屏幕下方反复显示「游戏流程已结束，请返回主菜单」。
3. 已发布 LAN 的房主**不应关闭服务器**；房主回主世界后只有自己的客户端显示缺失材质，**LAN 客人和服务端世界不受影响**。
4. 失败同样建立结局锁；本地失败存档显示「存档已损坏」且不可进入。
5. 从暂停菜单返回主菜单并重启客户端：退出始终可用，Alpha 呈现一直保留到 F8 恢复完成；待处理的 Windows 恢复事务不得提前退休 Alpha。

## F8 重置与存档隔离

0. **结局锁存在时主菜单的「单人游戏」「多人游戏」「Realms」全是灰的**，鼠标悬停给出对应结果的提示（成功：「成功结局已达成，按下F8重置MOD并重新体验」；失败：「失败结局达成，按下F8重新体验MOD」）。恢复完成后三个入口应立刻恢复可用。**注意区分**：存档隔离和服务器隔离仍然按存档/按地址分别封（在别人服务器上打完不会封掉你自己的存档），主菜单锁是另一回事——它是结局在恢复跑完之前不让游戏继续。
1. 结局锁存在时按 F8（**在主菜单上也要能按**，恢复入口不依赖任何界面），出现与成功/失败结果对应的恢复/重玩确认文案。
2. 确认后恢复 MOD 持有的桌面、记事本、窗口、资源包和演出状态，再正常关闭。
3. 重启后精确对应的本地结局存档因 `.thefourthfrequency-corrupted` 标记不可进入；成功显示「存档已封存」，失败显示「存档已损坏」。
4. 核对 `level.dat`、区块和玩家数据**没有被 MOD 改写**；新游戏必须使用新存档。
