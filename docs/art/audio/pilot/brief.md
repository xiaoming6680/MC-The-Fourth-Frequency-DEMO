# 音效升级样板：五组声音

状态：五组公开授权素材样板已完成导出，14 段声音通过技术检查。AI 服务因浏览器登录限制未使用；主观试听待用户反馈，未替换游戏内的 RC.3。

[完整 57.5 秒 A/B 试听](comparison.ogg) · [三形态咆哮](boss_roar_AB.ogg) · [完整激光](mouth_laser_AB.ogg) · [触手](tendril_strike_AB.ogg) · [HIM](him_presence_AB.ogg) · [终端](terminal_handling_AB.ogg)

每组先播放 A（RC.3），间隔 0.65 秒后播放 B（公开素材分层版），同组匹配综合响度。合集为近场编辑混音，没有游戏内空间衰减及 BGM；它不是实战录音。详细来源、每层剪辑参数、文件哈希和实测值见 [制作清单](recorded-material-manifest.json)。

本次使用 23 份外部录音/设计音效，Python 仅承担剪辑、滤波、速度变化、分层、导出和测量；未运行旧的振荡器/噪声合成器。部分来源本身是加工后的科幻效果，不能把全部素材称作未经处理的实录。源 Ogg 的有损属性如实保留在记录中。

以 RC.3 为对照。目标是增加可辨认的实体材质、动作力度与近场细节。原 BGM、事件 ID、多人隔离和声音生命周期继续沿用。

## 制作范围

| 样板 | 分层方向 | 最终事件长度 | 听感验收重点 |
|---|---|---|---|
| 三形态 BOSS 咆哮 | 喉腔主体、受力结构、呼气；三个阶段逐步扩大体量 | 2.8 / 3.3 / 4.1 秒 | 同一个生命体的进化；普通音箱也能听出规模；避免仅降低音高 |
| 完整嘴部激光 | 蓄力、发射瞬态、持续束流、落点、衰减独立制作 | 4.5 / 2.2 / 2.8 循环 / 0.8 / 0.7 秒 | 蓄力给出可读的危险；起射有释放力量的瞬间；持续层不盖住其他攻击 |
| 触手击地 | 筋腱绷紧、主体击地、碎屑、拖拽回收 | 1.5 / 1.1 / 0.65 秒 | 张力来自绷紧到释放的变化；不是每次动作都爆炸 |
| HIM 近身 | 衣料、鞋底微移、极轻气息 | 1.15 秒 | 很近、克制、像真的站着一个人；没有恐怖片配乐或突兀尖叫 |
| 终端开合 | 布料拿取、外壳/铰链、机械止挡 | 0.55 / 0.45 秒 | 手中物件的尺度；开与关不同；频繁操作也不刺耳 |

`cues.json` 中 14 个条目对应上述五组，保留为后续 AI 候选规格；当前样板使用外部素材，每条先做一个候选。源素材允许比成品长，剪辑决定准确落点，避免把整段素材强制变速来对齐动画。终端收起目标 0.45 秒，小于生成服务当前 0.5 秒下限，因此后续 AI 原料需先生成更长片段再裁剪。

## 动画与空间

- 激光：动作开始为 0，4.5 秒进入发射，6.5 秒退出束流。持续素材 2.8 秒用于循环；实际播放由动作控制结束。发射瞬态与持续声要共同试听，避免双重低频叠加。落点在命中位置发声。
- 触手：预备从 0 开始，1.6 秒击地，1.85 秒开始回收。击地声音的主体必须在事件开始后立即出现，尾部碎屑可与回收相交。
- 客户端中途加入攻击：现有代码从素材起点播放蓄力声；后续接入需要实际检查迟到场景，不能仅凭素材长度声称与动作完全对齐。
- HIM：使用既有观察者私有触发，保留稀疏间隔与安静消失。终端使用现有开合状态，反向操作停止上一段。
- 世界定位素材最终单声道；避免将固定左右声像烘焙进嘴部或落点。试听合集应另外提供实际距离和 BGM 环境下的游戏录音。

## 素材与导出

优先保存服务实际提供的无损源文件；记录真实编码、采样率、生成服务/模型、提示词、生成日期和来源许可，不把有损源转成 WAV 后宣称无损原录音。真实拟音采用已有明确授权的源素材，未取得素材前不声称完成实录分层。

生成原料与编辑工程放在忽略的 `build/audio-pilot/`；本目录保存明确标为待试听的样板和来源记录，不进入运行时资源。原始素材 ZIP、24-bit PCM 编辑母版和 32-bit float 分层轨保存在该构建目录；`pilots.rpp` 可继续编辑。当前电脑未发现 REAPER，工程文件尚未经过 REAPER 打开验证，不能将文件生成称为 DAW 验收通过。

复现：先安装 `tools/audio-requirements.txt`，然后运行 `python tools/build_audio_pilot.py`。脚本从下列发布页的下载地址取素材，以浮点处理保留余量；仅修改本样板目录和 `build/audio-pilot/`，不写入 MOD 音效资源。它不执行 AI API 请求。

## 素材署名

- OwlishMedia / owlstorm — [Sound Effects Pack](https://opengameart.org/content/sound-effects-pack)，发布页声明 CC0。使用布料、人声、碰撞、设备、液体及科幻设计素材。
- StarNinjas — [16 Monster Growls](https://opengameart.org/content/16-monster-growls)，发布页声明 CC0；[作者主页](https://opengameart.org/users/starninjas)。本样板选择第 8、11 段，其他部分源录音测得较大解码峰值，未选用。
- Kenney — [Impact Sounds](https://kenney.nl/assets/impact-sounds)，发布页与包内 License.txt 声明 CC0。使用拳击、石材、地毯和轻木质接触素材。

自动检查覆盖：完整解码、声道、时长、削波与真峰值、循环接缝。人工复听需要判断生命感、重量、恐怖氛围、重复疲劳和多人同时攻击时的可辨认性。试听未通过前不全量替换 242 个文件，也不标记 AAA 验收通过。

本轮实测：14 个单声道 48 kHz 导出全部完整解码通过，时长误差不超过 1 ms，最高真峰值 −3.84 dBTP；五组 A/B 的综合响度差不超过 0.04 LU。五个分组试听亦完整解码，最高真峰值 −2.95 dBTP。循环接缝通过数值阈值，仍需耳听确认。未重新运行游戏测试，因为本轮没有改动游戏代码或运行时资源；旧版测试结果不能当作新版样板在游戏内的验收。
